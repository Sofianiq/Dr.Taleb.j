# تطبيق مستشفى الدكتور طالب الجنابي الأهلي

**بإدارة الدكتور طالب الجنابي** — أول مستشفى أهلي في مدينة الفلوجة (تأسست عام ٢٠٠٢)

تطبيق ويب تقدّمي (PWA) يعمل على المتصفحات ويمكن تثبيته على هواتف **Android** و**iPhone** كتطبيق مستقل.
البيانات **لحظية** عبر Firebase: أي تعديل يقوم به أحد المستخدمين يظهر فوراً على أجهزة الجميع، ويعمل التطبيق حتى عند انقطاع الإنترنت ثم يزامن التغييرات تلقائياً عند عودة الاتصال.

---

## المميزات

| القسم | المحتوى |
|---|---|
| **الواجهة الترحيبية** | نبذة عن المستشفى وزر «التالي» ثم صفحة تسجيل الدخول |
| **الطبيب المقيم** | الردهات الافتراضية: **الجراحة** (٢٠ غرفة)، **القسطرة** (٥ أسرّة)، **الخدج** (٥ أسرّة)، مع إمكانية إضافة ردهات أخرى وتعديل كل شيء من الإدارة. لكل ردهة خريطة أسرّة ملوّنة حسب الحالة (مستقر، حرج، جاهز للخروج، شاغر، محجوز، تنظيف وتعقيم) |
| **بطاقة المريض** | الاسم، العمر، الجنس، الطبيب المختص، نوع العملية/الإجراء/التشخيص، هاتف ذوي المريض (واتساب)، تاريخ الدخول ومدة الرقود، الملاحظات. **سجل علامات حيوية** لكل قراءة مع الوقت واسم من سجّلها، و**مخطط** لتطوّر كل علامة، وتنبيه لوني للقيم غير الطبيعية حسب فئة المرضى (بالغون / حديثو الولادة). **نقل** المريض بين الأسرّة والردهات و**إخراجه** مع نوع الخروج |
| **الطباعة / PDF** | استمارة «متابعة المرضى والعمليات» (١٠ بطاقات في الصفحة) مطابقة للنموذج الورقي، **تقرير تسليم الشفت** لجميع المرضى، و**ملخص حالة مريض** مع سجل علاماته الحيوية. طباعة مباشرة أو تنزيل PDF أو مشاركته عبر واتساب |
| **الكادر الطبي** | الأقسام (قابلة للتعديل من الإدارة) مع **دليل هواتف** واتصال مباشر عبر **واتساب** |
| **الاستعلامات** | البحث عن أي مريض ومعرفة ردهته وسريره، مراسلة ذويه، الخفارة الحالية، أرقام الاستعلامات |
| **الكولات** | جدول خفارات ٢٤ ساعة على مدار الشهر، تمييز خفارة اليوم، نسخ جدول الشهر السابق، طباعة وPDF |
| **الإدارة** | مؤشرات المستشفى (الإشغال، الحالات الحرجة، الدخول والخروج اليومي)، الحالات الحرجة، التبليغات اللحظية، **سجل النشاطات** (من عدّل ماذا ومتى)، سجل المرضى المُخرَجين، إدارة الردهات والأقسام ومناصب الخفارة |

> الحسابان مشتركان بين أكثر من شخص، لذلك يُسأل مستخدم كل جهاز عن اسمه مرة واحدة ويُسجَّل الاسم مع كل تعديل.

## الحسابات والصلاحيات

| الحساب | البريد | الصلاحيات |
|---|---|---|
| الإدارة | `admin@dr.taleb.com` | صلاحيات كاملة: الردهات وأعداد أسرّتها وأرقامها، الأقسام، دليل الهواتف، جدول الخفارات، التبليغات، الإعدادات |
| الكادر (أطباء وممرضون) | `staff@dr.taleb.com` | إدخال المرضى ومتابعتهم وتسجيل العلامات الحيوية ونقلهم وإخراجهم، والاطلاع على كل الأقسام |

> كلمات المرور **لا تُكتب في هذا المستودع لأنه عام**؛ تُحدَّد عند إنشاء الحسابين في Firebase (الخطوة ١ أدناه).
> يمكن لكل حساب تغيير كلمة مروره من داخل التطبيق (زر الحساب أعلى الشاشة، أو تبويب «الإدارة»).

## خطوات الإعداد في Firebase (مرة واحدة فقط)

افتح [Firebase Console](https://console.firebase.google.com/project/dr-taleb-j) للمشروع `dr-taleb-j`:

### ١) تفعيل تسجيل الدخول وإنشاء الحسابين
1. **Build ← Authentication ← Get started ← Sign-in method ← Email/Password ← Enable ← Save**
2. **Authentication ← Users ← Add user** وأضِف الحسابين بكلمتي المرور المعتمدتين:
   - `admin@dr.taleb.com`
   - `staff@dr.taleb.com`
3. **(مهم للأمان)** **Authentication ← Settings ← User actions** ← ألغِ تفعيل **Enable create (sign-up)** حتى لا يستطيع أحد إنشاء حسابات من خارج لوحة التحكم.

### ٢) إنشاء قاعدة البيانات
**Build ← Firestore Database ← Create database** ← اختر **Production mode** وأقرب موقع جغرافي (مثلاً الشرق الأوسط أو أوروبا).

### ٣) نشر قواعد الأمان
**Firestore Database ← Rules** ← انسخ محتوى ملف [`firestore.rules`](firestore.rules) والصقه ثم **Publish**.

هذه القواعد تجعل البيانات متاحة لحسابي المستشفى فقط، وتمنع حساب الكادر من تعديل ما يخص الإدارة.

> ⚠️ **عند كل تحديث يغيّر ملف `firestore.rules` يجب نشره من جديد**، وإلا ظهر في التطبيق شريط «لا توجد صلاحية للوصول إلى قاعدة البيانات».

## النشر (رفع التطبيق على الإنترنت)

### الخيار أ: Firebase Hosting (موصى به)
```bash
npm install
npm run build
npx firebase-tools login
npx firebase-tools deploy --only hosting,firestore:rules
```
سيصبح التطبيق متاحاً على: `https://dr-taleb-j.web.app`

### الخيار ب: GitHub Pages
الملف `.github/workflows/deploy.yml` ينشر التطبيق تلقائياً عند الدمج في فرع `main`.
فعّل ذلك من: **Settings ← Pages ← Source: GitHub Actions**.

## تثبيت التطبيق على الهاتف

- **Android (Chrome):** افتح رابط التطبيق ← قائمة المتصفح ⋮ ← **تثبيت التطبيق**.
- **iPhone (Safari):** افتح رابط التطبيق ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

يوجد أيضاً زر «تثبيت التطبيق على الهاتف» داخل التطبيق (زر الحساب أعلى الشاشة).

## للمطوّرين

- **التقنيات:** React 19 + TypeScript + Vite + Tailwind CSS 4 + Firebase (Auth + Firestore) + vite-plugin-pwa
- **التشغيل محلياً:** `npm install` ثم `npm run dev`
- **مع محاكيات Firebase:** شغّل `npx firebase-tools emulators:start --only auth,firestore` ثم `VITE_FIREBASE_EMULATOR=true npm run dev`
- **البناء:** `npm run build` (الناتج في `dist/`)

```
src/
  pages/        الصفحات: الترحيب، الدخول، الطبيب المقيم، الردهة، الكادر، الاستعلامات، الكولات، الإدارة
  components/   مكوّنات الواجهة (بطاقة السرير، نافذة المريض، مخطط العلامات الحيوية، دليل الهواتف...)
  data/         الاتصال اللحظي بقاعدة البيانات وعمليات الحفظ
  print/        تصاميم الاستمارات المطبوعة وملفات PDF
  lib/          إعدادات Firebase، تسجيل الدخول، التواريخ، أرقام الهواتف
firestore.rules قواعد الأمان
```

### هيكل البيانات (Firestore)
| المجموعة | الوصف |
|---|---|
| `settings/app` | مناصب الخفارة، الأقسام، وقت بدء الخفارة |
| `wards/{id}` | الردهة: الاسم، نوع الوحدة، عدد الأسرّة، العلامات الحيوية المتابَعة، فئة المرضى، الترتيب |
| `sheets/{wardId}` | ترويسة الاستمارة: التاريخ، الشفت، المقيم الدوري |
| `beds/{wardId_NN}` | السرير وحالته وبيانات المريض الحالي وآخر علامات حيوية |
| `observations` | سجل قراءات العلامات الحيوية لكل رقود (`admissionId`) |
| `activity` | سجل النشاطات |
| `archive` | سجل المرضى المُخرَجين ونوع الخروج |
| `contacts` | دليل الهواتف |
| `shifts/{YYYY-MM}` | جدول الخفارات الشهري |
| `announcements` | التعاميم والتبليغات |
